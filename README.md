# NGA版主管理增强工具
## NGA_WardenTool


## 特点

- **NGA 原生风格**：棕/米色配色方案，与 NGA 论坛 UI 融为一体
- **零依赖**：纯 JavaScript（ES5 兼容），`@grant none` 运行在页面上下文
- **无需配置 Cookie**：使用浏览器已有的登录态，通过标准 XHR 发送请求
- **入口走官方按钮系统**：锁隐树三个入口注册进 NGA 的 `postBtn`，和"引用/编辑/更多"并排，不是自建元素
- **响应式设计**：桌面端与手机端均可用；按钮尺寸跟随宿主页面，不写死字号内边距
- **本地缓存**：设置项和运行状态存储在 localStorage（前缀 `nga_warden_`），刷新/跳转页面不丢失

## 功能模块

### 1. 批量加分

对帖子楼层进行自动批量加分操作，支持跨页自动跳转和断点续传。

- **声望值**：正数加分，负数扣分，范围 -1500 ~ 1500
- **开关选项**：增加/扣除金钱、增加威望、给作者发送PM（基于 `js_admin.js` 的 `adminui.addpoint` 接口，opt = 4194304 + 1(金钱) + 2(威望) + 4(PM)）
- **加分说明**：自定义理由，自动 `encodeURIComponent` 编码
- **加分页数量**：包括当前页在内共加 N 页后自动停止（0 = 不限制）
- **停止楼层**：加到指定楼层后自动停止（0 = 不限制）
- **起始页智能识别**：若已在目标帖子则从当前页开始，否则跳转到第 1 页
- **高级设置**：
  - 只加分含附件楼层（通过 `#postattach{N}` 检测附件）
  - 包含关键词加分（命中任一关键词才加分，中文顿号 `、` 分隔）
  - 排除关键词加分（命中任一排除词则跳过）
- **加分间隔**：可调延迟（默认 50ms）
- **跨页自动续传**：通过 localStorage 保存运行状态，页面跳转后自动恢复加分
- **过页停止检测**：通过楼层集合签名比对，防止翻过最后一页后死循环
- **完成自动刷新**：加分任务结束后自动刷新页面
- **运行时面板自动弹出**：加分进行中打开目标帖子页面自动显示工具面板
- **实时日志**：显示每条加分的成功/失败状态

### 2. 贴内批量操作

对当前帖子页面（`read.php`）的所有回复楼层执行批量 topic_lock 操作。

- **操作类型**（7 种）：锁定隐藏(1026)、单锁定(1024)、单隐藏(2)、编辑(128)、下沉(16777216)、审核(512)、屏蔽(16384)
- **操作/解除开关**：ON = 操作(pon)，OFF = 解除(poff)，一键切换正向/反向操作
- **扫描当前页**：自动提取所有回复楼层的 TID、PID、用户名、附件标记
- **勾选列表**：每个回复可单独勾选/取消，支持全选和取消全选
- **操作间隔**：可调延迟（默认 50ms）
- **实时日志**：显示每条操作的成败结果，支持停止正在执行的操作

### 3. 用户回复操作

在用户回复页（`thread.php?authorid=`）扫描该用户的所有回复和主题，支持批量锁隐和复制。

- **回复列表**：扫描 `#topicrows .topic_content a[href*="pid="]` 提取 TID,PID 对，去重显示
- **主题列表**：扫描 `#topicrows .topic_content a[href*="tid="]` 提取 TID，去重显示
- **勾选操作**：回复和主题均支持单独勾选/取消、全选、取消全选
- **批量锁隐回复**：对已勾选的回复执行锁隐（pon=1026）
- **批量单锁定主题贴**：对已勾选的主题执行单锁定（pon=1024, pid=0）
- **复制已选**：支持将已勾选的回复/主题列表复制到剪贴板

### 4. 查看本帖举报

在帖子页（`read.php`）按 TID 拉取本帖的举报记录。

- **数据来源**：`POST /nuke.php?__lib=admin_log_search&__act=search`，响应是 `window.script_muti_get_var_store = {...}` 形式，用括号配平截出 JSON 再解析
- **刷新举报数据**：点按钮重新拉取当前页；顶部显示举报条数统计
- **列表**：按条展示举报内容与处理入口，超过一屏时列表区域内滚动

### 5. 锁隐树（锁隐回复树 / 锁隐作者树 / 锁隐页）

**移植自 NGA Warden Utils**（原作者 WaterEast），属精简移植。面板本页顶部有「来源」区块写明这一点。

三个入口注册进 **NGA 官方的楼层按钮系统**，不往楼层里塞自建元素：

- 出现位置：楼层悬停条的「管理」按钮组、以及「更多 → 管理」菜单
- 显示顺序：**锁隐页 | 锁隐作者树 | 锁隐回复树**
- 权限判定走官方 `ck()`（`postBtn.d[id].ck`），拿不到时回退 `hasWardenPermission()`
- 主楼（`pid=0`）只显示「锁隐回复树」，在那里点击等价于锁隐整帖

| 入口 | 作用范围 |
|---|---|
| **锁隐回复树** | 该楼 + 引用/回复了该楼的后续楼层；引用链用不动点迭代递归展开（A 引用 B、B 引用 C 时 C 也在范围内）。主楼上等价于锁隐整帖 |
| **锁隐作者树** | 该作者在本帖的发言 + 引用这些发言的楼层。只扫当前页前后各 N 页（N = 检索页数上限，默认 10） |
| **锁隐页** | 当前这一页的所有回复楼层（不含主楼）。不翻页、不展开引用链，只处理屏幕上已加载的层；已锁隐的楼层会跳过 |

- **结果浮窗**：显示检索页码范围、成功条数与楼层明细，并提供 `撤销`（逐条 `poff=1026`）、`继续到末页`（回复树未扫到末页时继续扫）、`整帖扫描`（作者树窗口未覆盖全帖时改扫全帖）
- **错误处理**：单条网络/权限错误逐条记入浮窗与面板日志，不中断整批；定位楼层所用接口若返回异常（HTML/限流），自动改用当前页已有数据继续
- **稳定性**：菜单完好时是空操作，只有被页面重渲染破坏才重建，因此正在悬停/准备点击的操作栏不会被挤掉；节奏为未就绪 250ms、就绪 2000ms 自适应

### 6. 设置

**基础开关**

- **删除登录按钮**：移除导航栏中的"登录"按钮
- **删除NGA水印**：清除 `.c2` 元素的内联样式
- **查看赞踩比**：每个楼层显示赞/踩计数（读 `commonui.postArg.data`）
- **显示非公开备注**：版主备注始终可见，无需悬停（需 GREATER 权限）

**重定向**

把论坛网址强制替换成你选择的域名，只在 NGA 的这五个域名之间跳转：

`bbs.nga.cn` · `g.nga.cn` · `nga.178.com` · `ngabbs.com` · `ngacn.cc`

- 选择「不重定向」即关闭该功能（默认关闭）
- 协议、端口、路径、查询串、锚点全部保留，只替换主机名
- 用 `location.replace` 跳转，不写历史记录，因此按返回键不会被弹回来形成循环
- 用了白名单校验：只有当前域名和目标域名都在上面五个之内才跳转，因此即使 `localStorage` 被改动也不会跳到任意站点

**次级NUKE默认值**（设置页内独立分组，详见下一节）：启用默认值 / 默认范围 / 默认禁言 / 默认声望 / 同时扣减威望 / 延时 / 删除此贴 / 两种默认操作说明

**关于**：工具名称、GitHub 仓库、开发者链接

### 附：次级 NUKE 默认值

官方「次级NUKE」弹窗打开时自动预填保存好的默认值，**不发送任何额外请求**。配置入口在面板「设置」页的「次级NUKE默认值」分组。

- **默认范围**：全论坛 / 本版面 / 本合集 / 本区内 / 大区内
- **默认禁言**：不选 / 禁言 N 天（含永久）
- **默认声望**：不扣减 / 扣减 N（可同时勾选「扣减威望」）
- **延时 / 删除此贴**：是否预勾选官方弹窗中的这两项
- **默认操作说明（主题 / 短信）**：仅在官方说明框**为空**时填入，不覆盖已输入内容
- **安全机制**：一旦检测到用户手动改过面板选项，本次不再回填；主 NUKE 弹窗不受影响
- 设置页提供「立即应用到已打开的弹窗」，不必关掉重开

## 技术实现

| 项目 | 说明 |
|------|------|
| 加分 API | `POST /nuke.php` → `__lib=add_point_v3&__act=add`，opt 位域 + value 声望值 |
| 锁隐 API | `POST /nuke.php` → `__lib=topic_lock&__act=set`，pon/poff 位域控制帖子状态 |
| 举报 API | `POST /nuke.php?__lib=admin_log_search&__act=search`，响应为 script_muti_get_var_store |
| opt 构建 | 基于 `js_admin.js` 的 `adminui.addpoint`，opt = 4194304(加减声望) + 1(金钱) + 2(威望) + 4(PM) |
| 帖子状态位域 | pon/poff = 1024(锁定) + 2(隐藏) = 1026(锁隐)；128(编辑)；512(审核)；16384(屏蔽)；16777216(下沉) |
| 已锁隐判定 | `type & (1024 \| 4)`。**刻意不用位 2**：参考实现用 `(2\|1024)`，会把 `2\|4=审核`(type 127) 误判成已锁隐而跳过 |
| 取数解析 | 回复数据被识别为 JSON / `script_muti_get_var_store` / 宽松对象字面量三种形态；另容忍 BOM、尾随逗号、回调包裹、双重编码，并在解析失败时按 GB18030 再解一次 |
| 页面扫描 | `read.php` 用 `[id^="postrow"], [id^="post1strow"]` + `[id^="pid"]` + `.userlink.author`；`thread.php` 用 `#topicrows .topic_content a` |
| 入口注入 | 注册 `postBtn.d[91/92/93]` 并写进 `postBtn.all["管理"]`，同时包装 `postBtn.genB`，把按钮作为「更多」单元格的兄弟 `<td>` 插入 |
| 入口健康检查 | 只做几个属性读取，按每个子开关分别判定该入口是否该在；完好则完全不碰 DOM |
| 缓存键 | 加分设置 / 运行状态 / 操作日志 / 应用设置 共 4 个 localStorage Key（前缀 `nga_warden_`） |
| 过页检测 | 楼层集合签名比对：连续两页楼层号完全一致 → 已翻过最后一页 |
| 运行状态 | `{ tid, currentPage, startPage, processedFloors, processedCount, lastFloorSet, startTime }` |
| 跨页续传 | 页面跳转前保存运行状态 → 新页面加载后 `init()` 检测并调用 `resume()` |
| 事件 | 事件委托（标签页切换、日志列表操作），Escape 关闭面板 |
| 样式 | NGA 配色（#492e1b / #fdf5e6 / #ba8b5a），CSS 以紧凑数组 join 格式注入 |

## 使用方法

### 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展
2. 新建脚本，把 [user.js](user.js) 的内容整体粘贴进去并保存
   （或直接把 `user.js` 拖进 Tampermonkey 的脚本管理页）

也可以直接下载本仓库的 [user.js](user.js)，内容即为发布产物，无需构建。

### 快速上手

1. 登录 NGA，页面顶部导航栏出现 **版主工具** 按钮（手机端在导航栏；找不到容器时退化为右下角悬浮按钮），点开面板
2. 「批量加分」页填 TID、声望值和加分页数 → 点「启动加分」
3. 「贴内批量操作」页（`read.php`）点扫描 → 勾选楼层 → 选操作类型 → 执行
4. 「用户回复操作」页（`thread.php?authorid=`）扫描该用户回复/主题后批量处理
5. 「查看本帖举报」页（`read.php`）点「刷新举报数据」
6. 帖子页把鼠标移到楼层上，悬停条的「管理」组里用 **锁隐页 / 锁隐作者树 / 锁隐回复树**；开关与日志在面板「锁隐树」页
7. 「设置」页配置基础开关与**次级NUKE默认值**


## 常见问题

**楼层上看不到锁隐入口？**

1. 确认本页刚加载完，等 1~2 秒再悬停（入口依赖 NGA 的 `commonui.postBtn`）
2. 确认该账号在本版有版主/管理权限——官方按钮系统不会给无权限的人渲染入口
3. 确认没有把对应的「启用锁隐回复树 / 启用锁隐作者树 / 启用锁隐页」关掉
4. 还不行就用 `tools/nga-dom-probe.user.js` 打印真实 DOM 结构排查

**报「无法解析回复数据：{...}」？**

NGA 的 `lite=js` 接口返回形态不稳定（纯 JSON / script store / HTML 拦截页）。现在解析器会依次尝试多种形态，并在都不行时报出**真实原因和响应片段**（是 HTML、限流、还是结构不认识）。把报错里那段响应发出来即可定位。

**次级NUKE默认值没生效？**

值只在官方「次级NUKE」弹窗打开时预填，且**不覆盖**已有内容、**检测到手动修改后本次不再回填**。可先用设置页的「立即应用到已打开的弹窗」验证。
