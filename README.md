# NGA版主管理增强工具
## NGA_WardenTool
NGA玩家社区网页版版主管理增强工具，包含批量加分、贴内批量操作、用户回复操作等功能模块。

## 特点

- **NGA 原生风格**：棕/米色配色方案，与 NGA 论坛 UI 融为一体
- **零依赖**：纯 JavaScript（ES5 兼容），`@grant none` 运行在页面上下文
- **无需配置 Cookie**：使用浏览器已有的登录态，通过标准 XHR 发送请求
- **响应式设计**：桌面端与手机端（≤768px）均可正常使用
- **本地缓存**：设置项和运行状态存储在 localStorage，刷新/跳转页面不丢失

## 功能模块

### 1. 批量加分

对帖子楼层进行自动批量加分操作，支持跨页自动跳转和断点续传。

- **声望值**：正数加分，负数扣分，范围 -1500 ~ 1500
- **开关选项**：增加/扣除金钱、增加威望、给作者发送PM（基于 `js_admin.js` 的 `adminui.addpoint` 接口，opt = 4194304 + 1(金钱) + 2(威望) + 4(PM)）
- **加分说明**：自定义理由，自动 `encodeURIComponent` 编码
- **加分页数量**：包括当前页在内共加 N 页后自动停止（0 = 不限制）
- **停止楼层**：加到指定楼层后自动停止（0 = 不限制）
- **起始页智能识别**：若已在目标帖子则从当前页开始，否则跳转到第 1 页
- **高级设置**：
  - 只加分含附件楼层（通过 `#postattach{N}` 检测附件）
  - 包含关键词加分（命中任一关键词才加分，中文顿号 `、` 分隔）
  - 排除关键词加分（命中任一排除词则跳过）
- **加分间隔**：可调延迟（默认 50ms）
- **跨页自动续传**：通过 localStorage 保存运行状态，页面跳转后自动恢复加分
- **过页停止检测**：通过楼层集合签名比对，防止翻过最后一页后死循环
- **完成自动刷新**：加分任务结束后自动刷新页面
- **运行时面板自动弹出**：加分进行中打开目标帖子页面自动显示工具面板
- **实时日志**：显示每条加分的成功/失败状态

### 2. 贴内批量操作

对当前帖子页面（`read.php`）的所有回复楼层执行批量 topic_lock 操作。

- **操作类型**（7 种）：锁定隐藏(1026)、单锁定(1024)、单隐藏(2)、编辑(128)、下沉(16777216)、审核(512)、屏蔽(16384)
- **操作/解除开关**：ON = 操作(pon)，OFF = 解除(poff)，一键切换正向/反向操作
- **扫描当前页**：自动提取所有回复楼层的 TID、PID、用户名、附件标记
- **勾选列表**：每个回复可单独勾选/取消，支持全选和取消全选
- **操作间隔**：可调延迟（默认 50ms）
- **实时日志**：显示每条操作的成败结果，支持停止正在执行的操作

### 3. 用户回复操作

在用户回复页（`thread.php?authorid=`）扫描该用户的所有回复和主题，支持批量锁隐和复制。

- **回复列表**：扫描 `#topicrows .topic_content a[href*="pid="]` 提取 TID,PID 对，去重显示
- **主题列表**：扫描 `#topicrows .topic_content a[href*="tid="]` 提取 TID，去重显示
- **勾选操作**：回复和主题均支持单独勾选/取消、全选、取消全选
- **批量锁隐回复**：对已勾选的回复执行锁隐（pon=1026）
- **批量单锁定主题贴**：对已勾选的主题执行单锁定（pon=1024, pid=0）
- **复制已选**：支持将已勾选的回复/主题列表复制到剪贴板

### 4. 设置

- **删除登录按钮**：开启后移除导航栏中的"登录"按钮
- **一键锁隐作者**：每个楼层添加"锁隐all"按钮，一键锁隐该用户楼内全部回复（需管理员权限）
- **删除NGA水印**：清除 `.c2` 元素的内联样式
- **查看赞踩比**：每个楼层显示赞/踩计数（`commonui.postArg.data`）
- **显示非公开备注**：将版主备注始终可见，无需鼠标悬停（需 GREATER 权限）
- **关于信息**：显示工具名称、版本号、GitHub 仓库、开发者链接

## 技术实现

| 项目 | 说明 |
|------|------|
| 加分 API | `POST /nuke.php` → `__lib=add_point_v3&__act=add`，opt 位域 + value 声望值 |
| 锁隐 API | `POST /nuke.php` → `__lib=topic_lock&__act=set`，pon/poff 位域控制帖子状态 |
| opt 构建 | 基于 `js_admin.js` 的 `adminui.addpoint`，opt = 4194304(加减声望) + 1(金钱) + 2(威望) + 4(PM) |
| 帖子状态位域 | pon/poff = 1024(锁定) + 2(隐藏) = 1026(锁隐)；128(编辑)；512(审核)；16384(屏蔽)；16777216(下沉) |
| 页面扫描 | `read.php` 使用 `[id^="postrow"]` 选择器 + `postauthor{N}`/`postattach{N}`；`thread.php` 使用 `#topicrows .topic_content a` |
| 缓存键 | 加分设置 / 运行状态 / 操作日志 / 应用设置 共 4 个 localStorage Key |
| 过页检测 | 楼层集合签名比对：连续两页楼层号完全一致 → 已翻过最后一页 |
| 运行状态 | `{ tid, currentPage, startPage, processedFloors, processedCount, lastFloorSet, startTime }` |
| 跨页续传 | 页面跳转前保存运行状态 → 新页面加载后 `init()` 检测并调用 `resume()` |
| 事件 | 事件委托（标签页切换、日志列表操作），Escape 关闭面板 |
| 样式 | NGA 配色（#492e1b / #fdf5e6 / #ba8b5a），CSS 以紧凑数组 join 格式注入 |

## 使用方法

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展
2. 将 `user.js` 导入油猴脚本插件
3. 登录 NGA 后，页面右上角（或手机端导航栏）出现"版主工具"按钮，点击即可打开工具面板
4. 在"批量加分"页设置参数后点击"启动加分"开始自动批量加分
5. 在"贴内批量操作"页扫描回复并选择操作类型执行批量操作
6. 在"用户回复操作"页（需在 `thread.php?authorid=` 页面使用）扫描回复/主题并执行批量操作
7. 在"设置"页管理各功能开关
